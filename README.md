## Features

- 🧠 **Effortless Note-Taking:** Minimal, intuitive interface designed for deep focus.  
- 🔐 **Secure Authentication:** Sign up and log in to keep your notes private.  
- 📝 **Markdown Support:** Write notes with headings, lists, and formatting.  
- 🔍 **Instant Search:** Quickly find the note you’re looking for.  
- ☁️ **Cloud Sync (Planned):** Access your notes anywhere, on any device.  
- 📱 **Fully Responsive:** Beautiful experience on desktop, tablet, and mobile.  

> _“Simple enough for quick notes. Powerful enough for your next big idea.”_

## Tech Stack

| Layer | Technology |
|:------|:------------|

| **UI Components** | [Headless UI](https://headlessui.com/) & [lucide-react](https://lucide.dev/) |
| **Authentication** | e.g., NextAuth.js / Clerk / Custom JWT |
